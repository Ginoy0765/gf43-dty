Defaults

Set these once. Every operation — turning and milling — starts from these values, and you can still change any of them inside a specific operation without touching the default.

MATERIAL ▾

Applied to Turning, Grooving, Drilling, Threading and Job Setup. Open any operation and pick a different material there to override just that one — this default stays put.

TOOL CHANGE POSITION ▾

The safe position the tool returns to for a change. This lathe value flows into grooving/turning. The milling tool-change lives in the Milling section.

PROGRAM NUMBER ▾

Used as the O-number in the header of generated turning programs.

PROGRAM FILE FORMAT ▾

Sets the file extension used when you save a generated program (Save program, Full job, Drilling). The G-code text is identical — only the extension changes so the file matches what your control expects. Leave on Text if unsure.
Note: some browsers show a “this file could harm your device / Keep?” prompt for .prg (and occasionally other machine extensions) — that’s just the browser reacting to the extension, the file is plain-text G-code and is safe to Keep. Pick .nc if you’d rather avoid the prompt.

MACHINE SETUP ▾
TURNING / GROOVING FRAME · OD only · X = diameter, Z = spindle axis
MILLING FRAME · Z = tool axis, X & Y = table

Shows the frame for the current mode — chuck + turret in Turning, tool axis + direction in Milling. Rotary axes (A / B / C) come later.

ADVANCED — TURNING ▸

        

        

        

        

        

        
        

        

        
NPT profile only. When Yes, a finish pre-size program is written ABOVE the thread program, split by M01: external turns the OD to the major cone, internal bores the ID to the minor cone (NPT 1:16), each with a 45° lead chamfer. The chamfer starts 0.5 mm (dia) below the minor at the face for OD, or 0.5 mm above the major for ID. Only the length is needed — all diameters, the chamfer and feeds are computed. OD tool T0303 / ID tool T0505, 0.1 mm/rev finish feed.

Drill · Ream · Tap

            
OPERATION ▾

        
        

        
        
        
Rigid tapping (Fanuc). Emits M29 + G84 — the control handles the spindle/Z sync. Needs a rigid-tap function on the machine and a rigid holder. Pitch is used as feed/rev. Pre-drill the tap-drill hole first (run Drilling for that).

      

      
PATTERN ▸

        
        

        

        

        

        

        
1 hole

      

      
PARAMETERS ▸

        

        
        

        

      

      
CYCLE ▸

        
        

        

        

        
Auto fills every & distance from the drill diameter (full every 1×D, small ½×D, micro ¼×D); Manual leaves them to you. “Every” = depth of cut between retracts of that level; “distance” = how far it backs off (full clears to R above the face). Through-coolant skips the full retract.

        

        

        
ENTRY & EXIT ▸

          
          
ENTRY

          

          
EXIT (before breakthrough)

          

          

          
When Active, the first Distance of each hole uses the Entry RPM/Feed and the last Distance before breakthrough uses the Exit RPM/Feed (blank = keep the main value). The Coolant ON/OFF commands replace the default M08/M09 in the program.

        

        

      

      
POSITIONING ▸

        
Heights the drill uses between the safe height and the hole. Type to override the defaults.

        

        

        
Clearance R = plane above the face where rapid stops and feed begins. Safe Z = travel/retract height clear of the part & clamps. For patterns, choose whether the tool moves hole-to-hole at R (fast) or retracts to Safe Z (clears clamps).

      

      
ADVANCED — DRILLING ▸

        

        

          
Zone = previous end to its End depth (mm). P1 = peck/drill dist, P2 = retract/back-off (units above). Plunge: no retract. Full retract: peck P1, rapid fully out. Partial: drill P1, back off P2. Chip break: peck P1, tiny back P2.

          

        

        

          
Layered retract by counts: Full > Small > Micro. Degressive shrinks all three together (keeps full:small:micro ratio) by the reduction % each full cycle, until the limit; then the peck size holds constant to the bottom.

PATTERN ▸

        
        

        
        
Repeats the whole turned profile N times along the axis — the same pattern model as grooving's multi-groove. Roughing & finishing follow every copy; the profile preview shows them.

      

      
PARAMETERS ▸

        

        

        

        

        

        

        
Vc/RPM from material (threading values). Rough DOC = 2×nose R, rough feed = nose R÷4. Finish DOC = nose R÷2, finish feed = nose R÷8.

      

      
POSITIONING ▸

        
Safe position & G28 from Job Setup. Blank = auto (live value shown as placeholder); type to override. Roughing points use Rough OD/ID; finishing uses the profile.

        

        
        
Z bounds limit how far along the part roughing runs. Default: raw face → deepest profile Z.

      

      
CUT SETUP ▸

        

        

        

        
        

        
Stepped = constant-X passes ∥ Z. Copying = follow profile, offset by stock. Roughing = multiple passes; Finishing = single pass.
